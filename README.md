# 知映视频

Next.js + Remotion 的知识短视频编辑器，支持文案、图层、配音、字幕、视频导出及拼接。

## 效果组件

在“生成视频 → 效果”中添加组件。五类、十个内置预设可以叠加使用，最多 16 个：

| 类别 | 预设 | 主要调节 |
| --- | --- | --- |
| 网页动效 | 浮动信息卡、生长柱状图 | 文字、真实数值、圆角、浮动与生长速度 |
| 手绘画面 | 手绘荧光笔、手绘圈注 | 铅笔 / 宽笔刷、笔触强度、描绘速度 |
| 三维画面 | 旋转几何体、空间轨道 | 立方体 / 八面体、轨道数量、旋转速度 |
| 数学动画（Manim） | 公式推演、函数描线 | LaTeX 逐笔书写 / 公式变换、正弦 / 抛物线、振幅、频率、偏移与描线速度 |
| 镜头与时间线 | 片段淡入淡出、镜头推进 | 淡入 / 淡出、过渡底色、推进 / 平移、作用程度 |

选中组件后可调整出场起止、位置、大小、旋转、颜色、透明度、强度和速度；整幅画面的镜头效果只显示适用参数。支持显隐、复制、删除、上下移动和文字 / 图片图层前后叠放；字幕位于最前方。时间轴可逐帧定位，效果与配音使用同一视频时钟。勾选“结束跟随视频时长”后，延长视频时无需重新调整结束位置。

效果随现有草稿自动保存，旧草稿默认为无效果。预览、全屏预览、API 校验及 MP4 导出使用同一数据和画面组件；导出的效果也会保留在后续拼接中。

实现采用 HTML / SVG、Three.js 几何与透视投影、真实 Manim 渲染与现有 Remotion 时间轴。依赖与授权见 [效果组件说明](third-party/effects.md)。当前尚未接入 p5.js / p5.brush 和 HyperFrames。数学动画使用固定 Manim 场景，不接收任意 Python 代码或工程上传。

### Manim 数学动画

Windows 需要 Python 3.12 或更高版本。执行一次安装与真实公式检查：

```sh
npm run setup:manim
```

安装脚本创建 `.venv-manim/`，安装 Manim 0.20.1，并将独立的 Tectonic、TeX Live dvisvgm 与数学字体放入 `.tools/manim/`，不修改系统 PATH。可通过 `MANIM_BOOTSTRAP_PYTHON` 指定创建环境的 Python；已有环境通过 `MANIM_PYTHON` 指定其可执行文件。Linux/macOS 请先通过系统包管理器安装 `tectonic` 和 `dvisvgm`。首次编译会下载 TeX 宏包，安装检查会预热常用公式资源。

在「效果 → 数学动画」中加入公式或函数，修改参数后自动生成透明动画。公式支持逐笔书写、完整展示、原公式到目标公式的形状变换；函数支持 `y = A sin(ωx) + b` 和 `y = ax² + b`，坐标范围随参数调整。生成状态与错误显示在组件属性顶部，可重新生成。

Manim 使用 `MathTex/Write/TransformMatchingShapes/Axes/Create/MoveAlongPath` 实际输出 960×480 RGBA 帧序列。生成速度受公式复杂度影响，不保证像 CSS 一样即时响应；位置、尺寸、透明度和出场时间在合成时应用，不触发重新渲染。修改公式、颜色、线条强度、函数参数或动画速度会生成新缓存。帧序列保存在 `output/manim/`，刷新和服务器重启后可复用。动画完成后停留末帧，组件按自身起止时间显示。预览、全屏与成片共用这些帧，数学动画失败时导出明确报错。

现阶段支持上述预设和常用数学 LaTeX，不支持任意 Python 代码、TeX 自定义宏、文件读取命令或中文 TeX 正文。扩展 Manim 预设请修改 `scripts/manim/render_scene.py`，并升级 `MANIM_RENDER_VERSION`，避免复用旧场景帧。

## 本地启动

需要 Node.js 20.9 或更高版本；本次在 Windows、Node.js 24 和 Edge 上验证。

```sh
npm ci
npm run dev
```

打开 http://localhost:3000 。生产模式使用 `npm run build` 后运行 `npm start`。

## 完整功能 Demo

打开 **http://localhost:3000/demo** 进入可交互演示。首次点击“一键准备演示素材”后，服务会使用当前本机的中文音色和真实渲染管线生成三支可编辑样片：

- **数学微课**：Manim 公式变形、函数描线、图片图层、配音与字幕；
- **图文短片**：文字图层、网页卡片、数据图表和手绘标记；
- **三维讲解**：Three.js 几何体、空间轨道和镜头运动。

准备完成后，顶部 Demo 引导会按“文案 → 画面 → 图层 → 效果 → 配音 → 字幕”带着演示者走完整流程。工作区的导出按钮会生成真实 MP4，素材库可以重命名和选择片段，视频拼接页可以调整顺序并输出合集。Demo 使用独立的 `codevideo:demo:*` 浏览器草稿，不覆盖日常工作区；服务器生成的演示视频和配音保存在 `output/`，重复准备会复用已有记录。

准备环境：

```sh
npm run setup:manim
npm run build
npm start
```

已经准备好演示素材后，可运行 `npm run verify:demo` 检查真实视频播放与下载、Manim 画面、草稿隔离、切换与恢复、字幕深链、拼接排序和移动端。测试使用独立浏览器上下文，只清理本次保存的下载副本。

Windows 安装中文语音包后可使用本机配音。云端服务可配置 `TTS_API_KEY`（OpenAI 兼容接口），或 `AZURE_SPEECH_KEY` 和 `AZURE_SPEECH_REGION`；`TTS_PROVIDER=local|azure|openai` 可指定默认服务。

## 本次修复：正确性与保存

- **草稿恢复**：文案、模板、比例、配音设置、字幕修改、图层及位置自动保存；切换工作区、刷新和重启浏览器后可恢复。配音生成时切换到素材库也会保留生成结果。恢复时从服务器重新读取音频元数据。
- **过期配音拦截**：标题、正文、讲稿、音色或语速变化后，预览停用旧配音，导出按钮提示重新生成；服务端和渲染队列也独立校验。修改音量、颜色或图层无需重新合成配音。
- **统一音画时间轴**：标题与三段正文使用实际音频分段边界，六套模板和字幕共用这一时间依据；片尾淡出等待最后一句结束。

讲稿需要 **四段，每段另起一行**，依次对应标题、第一段、第二段和第三段。点击“从文案生成”可自动填好，再按需改写。旧版生成且不含分段时间轴的配音，需要重新生成后才能导出。单段视频仍为 5–15 秒，超过上限时请缩短讲稿、提高语速或拆成多段。

## 保存范围

当前实现为**每个浏览器、每个站点地址的一份草稿**，未包含多项目管理或云同步。`localhost` 与 `127.0.0.1`、不同端口的草稿各自独立。

音频、上传图片和成片存放在项目的 `output/` 目录，迁移已有项目时需保留该目录。清除浏览器站点数据会删除草稿；删除服务器音频文件后，文字草稿保留，但需要重新生成配音。损坏的草稿不会被空白默认值覆盖，界面会显示读取失败。

刷新可继续查看仍在服务器运行的导出任务；服务器进程重启后，尚未完成的任务不会自动续跑。恢复时会解除失效任务的占用，允许重新导出；已完成成片仍可在素材库查看。

## 全站排查修复

- 拼接工作区保存比例、背景及导出任务；切换页面、刷新后可恢复进度，失效任务可重新提交。导航支持浏览器前进、后退。
- 修改字幕后下载的 SRT 使用当前字幕文本与时间轴；配音下载使用 `.wav` 扩展名。
- 放大预览暂停底层播放，弹窗支持焦点进入与 Tab 循环；图层拖拽会在指针取消、失去捕获或窗口失焦时结束，第二根指针不能接管拖动。
- 图片属性根据当前画布比例计算尺寸，编辑器与导出共用图层清洗规则，最多 20 层。非法图片路径、重复图层编号、零时长窗口均被处理。
- 长字幕限制两行宽度，无标点长讲稿会继续分句；重叠或经帧取整后无时长的字幕被剔除。
- 图片上传检查格式结构与尺寸，限制 4000 万像素、单边 16384；图片素材支持删除，正在导出中使用的图片不能删除。
- 拼接时保护源视频不被删除，合并后的配音与字幕标记沿用源片段。素材库记录损坏会明确报错并保留原文件，不会按空库覆盖。
- 统一媒体 Range 解析与文件路径范围校验，非法图片文件名返回 400；损坏、截断或非 PCM 的 WAV 被拒绝。
- 单段与拼接成片提供独立“全屏播放”入口，保留播放进度、音量和倍速。原生全屏不可用或被拒绝时使用网页全屏；素材库与放大预览共用兼容处理。
- 预览播放器、单段成片和拼接成片统一使用全屏播放层；请求在点击事件内直接发起，浮层挂到页面根部，尺寸变化不再重新创建播放器。
- 本地网页点击视频下载会实际保存到系统“下载”文件夹并显示完整路径，避免内嵌浏览器忽略下载链接。文件重名时增加序号。该本机保存接口只接受本地同源请求；远程站点使用浏览器保存接口或下载链接。
- 适配 React Bits SpotlightCard（模板/素材卡片）和 AnimatedContent（工作区标题过渡）；支持键盘、触屏及减少动态效果偏好，不增加动画依赖。[来源与适配说明](third-party/react-bits.md)。

## 验证

```sh
npm test
npm run build
npm run verify:correctness
npm run verify:site
npm run verify:fullscreen
npm run verify:react-bits
npm run verify:playback-download
npm run verify:effects
npm run verify:manim
```

- `npm test`：覆盖草稿、配音、字幕、图层、效果组件、Manim 缓存与参数校验、媒体格式、路径、素材库保护、五种画布比例和本地文件保存。
- `verify:correctness`：启动独立生产服务器并在浏览器操作，覆盖草稿恢复、服务重启、音频丢失、过期请求、移动端布局，以及真实 TTS 和 MP4 导出。先完成生产构建；Windows 默认使用 Edge 和本机中文音色。其它环境需提供可用 TTS 和 Playwright Chromium（`npx playwright install chromium`），也可通过 `BROWSER_PATH` 指定浏览器、`TEST_PORT` 修改测试端口。
- 验证结果和截图写入 `test-results/correctness/`，测试结束会关闭自己启动的服务器。测试会在 `output/` 中新增音频、图片和成片，请使用开发环境运行。
- `verify:site`：需先运行本地服务，默认使用 `http://127.0.0.1:3000`（`TEST_BASE_URL` 可覆盖）。测试六套模板的真实 MP4 导出、拼接、重命名、删除保护、字幕下载、图片操作和桌面/390px 布局。结果写入 `test-results/site/`，只删除本次创建的测试视频和图片。浏览器拖拽中断测试使用 Edge 合成 PointerEvent，未覆盖实体触屏设备。

原有 `scripts/verify-voice.mjs` 已适配四段讲稿和内容绑定，需另行启动 3000 端口服务器后运行；它包含额外的语速、长短讲稿和拼接测试。

`verify:fullscreen` 同样需要本地服务，使用实际单段及拼接 MP4 验证进入/退出全屏、进度/音量/倍速、焦点与滚动恢复，以及 390px 移动端全屏能力关闭或请求被拒绝时的网页全屏。素材库需已有至少一个可拼接片段。结果与截图写入 `test-results/fullscreen/`，仅清理本次创建的成片；未实测 iOS Safari 真机。

`verify:react-bits` 需要本地服务和已有素材，覆盖鼠标/键盘/触屏、动态偏好、光效不拦截按钮、模板选择、素材播放/重命名取消/搜索、切页保留文案与桌面/390px 布局。结果与截图写入 `test-results/react-bits/`，不会修改服务器素材。

`verify:playback-download` 需要本地服务和已有素材。16 项检查覆盖预览尺寸变化、原生全屏、真实受限 iframe 中的网页全屏，以及系统下载文件夹中的 MP4 存在性、字节校验、重名保护和保存反馈。仅清理本次测试保存的下载副本，不删除已有文件。结果写入 `test-results/playback-download/`；真实 iframe 测试不等于实测 Codex 宿主本身。

`verify:effects` 需要本地服务，验证十种组件的增删、复制、排序、显隐、调参、时间边界、草稿恢复、LaTeX 和三维样式、桌面 / 手机操作，以及从网页发起真实 MP4 导出、解码检查八种视觉组件颜色、成片全屏。仅删除本次测试创建的素材库视频，演示 MP4 与报告保留在 `test-results/effects/`。

`verify:manim` 需要完成 Manim 环境安装并启动本地服务。验证真实公式变换 / 函数参数、透明字形帧、缓存复用、草稿恢复、逐帧拖动、起止边界、末帧停留、全屏及 390px 控件，并实际导出与解码 MP4 检查两个数学图层。报告、截图、Manim 帧及演示视频保存在 `test-results/manim/`；仅清理本次测试成片。
